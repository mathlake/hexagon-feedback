# Hexagon feedback

This is the public feedback and issue tracker for [Hexagon](https://hexagonmath.org),
a repository for scholarship in the age of AI. The Hexagon application source
code is not hosted here.

## How to participate

- [Report a bug](https://github.com/mathlake/hexagon-feedback/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/mathlake/hexagon-feedback/issues/new?template=feature_request.yml)
- [Report a documentation problem](https://github.com/mathlake/hexagon-feedback/issues/new?template=documentation.yml)
- Use [Discussions](https://github.com/mathlake/hexagon-feedback/discussions) for questions and early-stage ideas.

Please search existing issues first and add context to an existing report when
one matches. Issues are public: do not include passwords, access tokens, private
papers or source files, personal information, or account-specific details.

## What happens next

Maintainers will triage reports as capacity permits. Labels communicate the
current state; an issue being open or labeled `planned` is not a promise of a
particular release date. We may close reports that are duplicates, out of scope,
not reproducible, or better handled in a Discussion.

## Security and privacy

Do not report a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md)
to make a private report. For a privacy request, email admin@hexagonmath.org.

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
